# 1.0.0 → 1.1.0

Minor release. Adds the game-agnostic pattern suite and four supporting domain
components. Everything is additive: no existing prop contract, token, or item
changes. Immutable `1.0.0` artefacts remain available and unchanged.

## What changed

1. **New patterns** (nine, all `category: "pattern"`):
   - `decision` — core sealed → declaration → negotiation → lock → resolve loop
     (a vote is the degenerate sealed → resolved case).
   - `timed-round` — round/beat container with countdown, phase progress,
     directive, and action footer.
   - `briefing` — paced slide-deck walkthrough.
   - `scripted-reveal` — timed mid-round announcement and reveal.
   - `results` — staged outcome reveal (outcome summary + stat grid).
   - `debrief` — facilitated reflection (What / So What / Now What).
   - `facilitator-console` — session control strip with participant status,
     connection state, and progress.
   - `shared-display-game` — in-game shared-display states (waiting, active,
     reveal, results, debrief).
   - `attention-takeover` — full-surface "watch the display" redirect.
2. **New domain components** (four, all `category: "component"`):
   - `option-selector` — single-choice option list.
   - `intensity-selector` — discrete 0..max intensity/conviction selector.
   - `stat` — single metric tile.
   - `rating` — star rating input/display.

## Consumer actions

1. **Pin** to `versions/1.1.0` when adopting the new patterns.
2. **Install** the patterns you need, e.g.:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.1.0/r/decision.json"
   ```

3. **Prefer patterns** over hand-assembled primitives for the game loop; see
   [pattern-composition.md](../pattern-composition.md).
4. Patterns own presentation and beat choreography only — inject state and
   callbacks (networking, scoring, stage authority) via props.
5. No migration is required for consumers not adopting the new items; existing
   installations continue to work unchanged.

## Unchanged

- Existing item names and prop contracts (0.5.0 domain set, shells, primitives)
- Semantic token names and themes
- `join-flow`, `lobby`, and `shared-display-lobby` patterns
