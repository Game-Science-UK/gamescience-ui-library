# 0.5.1 → 0.5.2

Patch release. Public component APIs and theme contracts remain
backward-compatible. Immutable `0.5.1` artefacts are unchanged.

## What changed

1. **Storybook coverage** — deepened named stories for patterns (join/lobby),
   shells, game-domain components, and previously playground-only UI primitives.
2. **Coverage gate** — `npm run storybook:coverage` fails when a public export
   lacks a dedicated story or required pattern/shell states are missing. Wired
   into `validate`.
3. **Version metadata** — registry item `meta.version` and `@gamescience/base`
   consumer guidance stamp to `0.5.2`. No source component contract changes.

## Consumer actions

1. **Optional pin** to `versions/0.5.2` when you want the current library pin.
2. **No component reinstall required** for visual or API behaviour — stay on
   `0.5.1` if you only need the Citadel Panel fix from that cut.
3. If you pin to `0.5.2`, **diff then reinstall** `@gamescience/base` so
   `src/lib/version.ts` and `src/docs/gamescience-ui*.{json,md}` report
   `0.5.2`.
4. No route, pattern, or domain component contract changes.

## Unchanged

- Catalogue item names and count (no additions or removals)
- Theme CSS and token contracts from 0.5.1
- Pattern and domain component contracts from 0.5.1
