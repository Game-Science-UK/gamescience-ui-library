# 0.5.4 → 1.0.0

Major release. Colour tokens move from **HSL channel triplets** to **OKLCH
channel triplets**. Consumers that still wrap tokens with `hsl(var(--token))`
must update mappings before visuals will resolve correctly. Immutable `0.5.4`
artefacts remain available and unchanged.

## What changed

1. **OKLCH colour contract** — theme CSS (`theme-gamescience`, `theme-citadel`)
   and foundation tokens (`base`) author colours as OKLCH channels
   (`L C H`, for example `0.545 0.215 262.7`). Consumption is
   `oklch(var(--token) / <alpha-value>)` (Tailwind 3) or
   `oklch(var(--token))` (Tailwind 4 bridge / foundations).
2. **GameScience background** — light GameScience `--background` is pure white.
3. **GameScience secondary Button** — no drop shadow; focus ring retained on
   `:focus-visible`. `Button` exposes `data-intent` for theme targeting.
4. **Storybook IA** — Introduction / Foundations / flat Components + Examples
   gallery (All Components, Patterns, Shells, Forms, Cards, Game Surfaces);
   centered fitted docs canvases; hosted Storybook layout polish.

## Consumer actions

1. **Pin** to `versions/1.0.0` (do not rely on unversioned `/r/` for production).
2. **Diff then reinstall** at least:
   - `@gamescience/base`
   - `@gamescience/theme-gamescience` and/or `@gamescience/theme-citadel`
   - `@gamescience/button` (secondary shadow + `data-intent`)
3. **Update Tailwind colour mappings**:
   - Replace every `hsl(var(--token)…)` with `oklch(var(--token)…)`.
   - Tailwind 3: copy the map from [tailwind-v3-integration.md](../tailwind-v3-integration.md).
   - Tailwind 4: replace the local bridge copy with the updated
     `consumer/tailwind-v4-bridge.css` from this version (or reinstall guidance
     that ships it).
4. **Do not** leave mixed `hsl()` wrappers against OKLCH channels — colours will
   be wrong or invalid.
5. Confirm `src/lib/version.ts` and `src/docs/gamescience-ui*.{json,md}` report
   `1.0.0`.
6. Smoke GameScience and Citadel (participant / facilitator / shared-display)
   after the token remap.
7. Storybook-only changes need no consumer install; use hosted `/storybook/` as
   the rendered reference for 1.0.0.

## Unchanged

- Catalogue item names and set (no registry additions/removals)
- Semantic token **names** (still `--primary`, `--background`, …)
- Pattern / shell / domain component prop contracts (except Button `data-intent`)
