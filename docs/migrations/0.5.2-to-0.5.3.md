# 0.5.2 → 0.5.3

Patch release. Public component APIs and theme contracts remain
backward-compatible. Immutable `0.5.2` artefacts are unchanged.

## What changed

1. **Hosted Storybook** — static Storybook is published on GitHub Pages at
   `/storybook/` with a main-nav link. Build output uses relative asset URLs
   suitable for the project Pages subpath.
2. **Migration coverage ledger** — migrate composer modules and skills deepen
   the obligation-ledger / coverage dimensions A–E model (source, call-site,
   render-path, theme-contract, visual). Full visual alignment expects an
   independent post-migration coverage audit.
3. **Version metadata** — registry item `meta.version` and `@gamescience/base`
   consumer guidance stamp to `0.5.3`. No source component contract changes.

## Consumer actions

1. **Optional pin** to `versions/0.5.3` when you want the current library pin.
2. **No component reinstall required** for visual or API behaviour — stay on
   `0.5.2` if you only need that cut’s Storybook coverage gate.
3. If you pin to `0.5.3`, **diff then reinstall** `@gamescience/base` so
   `src/lib/version.ts` and `src/docs/gamescience-ui*.{json,md}` report
   `0.5.3`.
4. Prefer the updated migrate / validate / audit skills (or regenerate a
   migrate brief from the Pages composer) when running new migrations.
5. No route, pattern, or domain component contract changes.

## Unchanged

- Catalogue item names and count (no additions or removals)
- Theme CSS and token contracts from 0.5.2
- Pattern and domain component contracts from 0.5.2
