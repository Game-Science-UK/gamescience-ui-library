# 1.2.1 → 1.2.2

Patch release. Visual correction to the `switch` off-track treatment in the
`gamescience` theme only. No prop contract, token, component, or item-name
changes. Immutable `1.2.1` (and earlier) artefacts remain available and
unchanged.

## What changed

1. **`theme-gamescience`** — the `switch` off (unchecked) track now resolves to a
   visible surface (`oklch(var(--border))`) instead of rendering with no fill,
   which previously left the white thumb indistinguishable from the white
   background. The checked state remains `primary`.

The change lives entirely in `src/themes/gamescience.css`; the `switch` component
contract is unchanged and the `citadel` theme is unaffected.

## Consumer actions

1. **Pin** to `versions/1.2.2` when adopting the switch off-track correction.
2. **Reinstall the theme** you use:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.2.2/r/theme-gamescience.json"
   ```

3. Consumers not using the `gamescience` theme require no action; existing
   installations continue to work unchanged.

## Unchanged

- All item names and prop contracts (the 1.2.1 set)
- Theme and foundation token contracts
- The `switch` component and its `citadel` theme treatment
