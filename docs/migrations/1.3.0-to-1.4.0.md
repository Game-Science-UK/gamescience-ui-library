# 1.3.0 → 1.4.0

**Breaking for consumers using the Sentinel theme.**

1.4.0 removes the `sentinel` theme from the registry. The theme was implemented
from an extraction brief whose component treatments did not match the source
application, and it is being re-derived through the revised extraction process.

## What changed

|               | Items                                                                     |
| ------------- | ------------------------------------------------------------------------- |
| **Removed**   | `theme-sentinel`                                                          |
| **Changed**   | `base` (theme contract: `SUPPORTED_THEMES` no longer includes `sentinel`) |
| **Unchanged** | All other item names, prop contracts, and payloads                        |

Supported themes are now `gamescience` and `citadel`.

## Register mechanism retained

The `register` prop, `data-register` sync, and `SUPPORTED_REGISTERS`
(`cinematic` | `restrained`) remain. They are theme-neutral and no longer
Sentinel-specific: a theme now declares its default register through
`THEME_DEFAULT_REGISTERS` in the theme contract rather than through a hardcoded
theme check in the provider.

No theme currently declares a default register, so `GameScienceProvider` sets no
`data-register` unless you pass one explicitly.

## Theme hooks retained

The `gs-*` hooks introduced alongside Sentinel — `gs-panel-wash`, `gs-overlay`,
`gs-display-hero`, `gs-title-section`, and `gs-card[data-state="breached"]` —
remain in the shared component source. They are theme-neutral and unstyled
unless a theme targets them. No component payload changed.

## If you are on `sentinel`

1. Stay pinned to `versions/1.3.0` — it remains immutable and continues to serve
   `theme-sentinel`.
2. Or switch to `gamescience` or `citadel`: change the `theme` prop on your root
   `GameScienceProvider`, install that theme item, and import its CSS in place of
   `sentinel.css`.

Projects on `gamescience` or `citadel` need no changes beyond reinstalling `base`
if they want the updated theme contract.
