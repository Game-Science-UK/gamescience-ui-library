# 1.1.1 → 1.2.0

Minor release. Adds the `create-session` facilitator pattern. Everything is
additive: no existing prop contract, token, theme, or item changes. Immutable
`1.1.1` (and earlier) artefacts remain available and unchanged.

## What changed

1. **New pattern** (`category: "pattern"`):
   - `create-session` — facilitator-facing create-session form with optional
     host and session names, an application-owned configuration slot for
     game-specific options (duration, naming, rehearsal tools, etc.), and a
     ready state showing the generated room code.
2. **Participant list presentation** — `facilitator-console` and `lobby` now
   render their participant lists as a single-column list instead of a
   2–3 column grid, so readiness badges and connection status no longer
   overflow the card edge.

## Consumer actions

1. **Pin** to `versions/1.2.0` when adopting the new pattern.
2. **Install** the pattern you need:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.2.0/r/create-session.json"
   ```

3. Code generation, persistence, networking, and any game-specific
   configuration remain application-owned — inject them via `onSubmit`,
   `createdCode`, and `configSlot`.
4. No migration is required for consumers not adopting the new item; existing
   installations continue to work unchanged.

## Unchanged

- Existing item names and prop contracts (the 1.1.1 set)
- Theme and foundation token contracts
- The 1.1.0 pattern suite and four domain components
