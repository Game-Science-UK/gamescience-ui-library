# 0.4.0 → 0.4.1

Patch release. Public APIs remain backward-compatible. Immutable `0.4.0`
artefacts are unchanged.

## What changed

1. **Button `asChild` + `loading`** — fixed. Radix `Slot` previously received a
   spinner sibling plus the child element and threw `React.Children.only`.
   Loading indicators are now injected **inside** the single child element.
2. **Migration governance** — coverage language, canonical project state record
   (`src/docs/gamescience-ui-state.json`), slice reconciliation, mixed-context
   route detection, and visual-loss reporting are required in Migrate briefs.
3. **SharedDisplayLobby** — no API change. Application-owned visuals (QR, radar,
   illustration) should compose as shell siblings; a neutral `visual` slot is
   deferred pending broader evidence.

## Consumer actions

1. **Pin** to `versions/0.4.1`.
2. **Diff then reinstall** `@gamescience/button` (and `base` if you want updated
   guidance / version metadata).
3. The workaround of calling `buttonVariants()` on an anchor remains valid but
   is **no longer required** — `<Button asChild loading><a/></Button>` works.
4. No automatic application changes occur. No route changes are required.
5. Optionally adopt `src/docs/gamescience-ui-state.json` and reconcile it with
   the Markdown migration record after each slice.

## Unchanged

- Catalogue item names and count (no additions or removals)
- GameScience and Citadel theme CSS (unless only version metadata in `base`)
- Pattern contracts for join / lobby / shared-display lobby
