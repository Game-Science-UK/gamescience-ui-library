# 0.5.0 → 0.5.1

Patch release. Public APIs remain backward-compatible. Immutable `0.5.0`
artefacts are unchanged.

## What changed

1. **Citadel Panel scope corners** — strong emphasis panels no longer override
   corner colour to Cobalt (`--accent`). Corners match other panel states
   (Pacific / `--border-strong`).
2. **Citadel Panel border thickness** — raised and strong emphasis panels no
   longer stack a 1px CSS border with a 1px ring from `--shadow-card`. Panel
   shadows use depth-only tokens so the border stays 1px. Foundations also pin
   `.gs-panel { border-width: var(--border-width-panel); }`.
3. **Citadel Panel strong border colour** — strong emphasis explicitly uses the
   same Pacific border colour as other panel states. Cobalt glow is unchanged.

## Consumer actions

1. **Pin** to `versions/0.5.1`.
2. **Diff then reinstall** `@gamescience/base` and `@gamescience/theme-citadel`
   if you use Citadel (Gamescience theme is unaffected visually).
3. No component API changes. No route or pattern contract changes.
4. Confirm `src/lib/version.ts` and guidance report `0.5.1`.
5. Smoke Panel elevations + `emphasis="strong"` under Citadel.

## Unchanged

- Catalogue item names and count (no additions or removals)
- GameScience theme CSS (aside from shared `base` version/guidance metadata)
- Pattern and domain component contracts from 0.5.0
