# 1.1.0 → 1.1.1

Patch release. No component or pattern API changes. The only payload change is
the `base` item's consumer guidance file, which now names the full 1.1.0 pattern
suite so the Lovable agent discovers every available pattern.

## What changed

1. **Consumer agent guidance** — `src/docs/gamescience-ui-guidance.md` (shipped
   inside `@gamescience/base`) now enumerates all twelve patterns
   (`join-flow`, `lobby`, `shared-display-lobby`, `decision`, `timed-round`,
   `briefing`, `scripted-reveal`, `results`, `debrief`, `facilitator-console`,
   `shared-display-game`, `attention-takeover`) instead of only the three
   pre-1.1.0 join/lobby patterns.

## Consumer actions

1. **Pin** to `versions/1.1.1` if you want the updated guidance.
2. **Reinstall `@gamescience/base`** to refresh the guidance file:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.1.1/r/base.json" --diff
   ```

3. No component, pattern, theme, or token changes — existing installations work
   unchanged if you do not need the updated guidance text.

## Unchanged

- All 86 registry item names and prop contracts
- `decision`, `timed-round`, `briefing`, `scripted-reveal`, `results`, `debrief`,
  `facilitator-console`, `shared-display-game`, `attention-takeover`, and the
  four domain components added in 1.1.0
- Theme and foundation token contracts
