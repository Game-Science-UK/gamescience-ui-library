# 0.4.1 → 0.5.0

Minor release. Adds reusable game/domain components for discussion, voting, and
results compositions. Immutable `0.4.1` (and earlier) artefacts are unchanged.

## What changed

### Added registry items

- `countdown`
- `phase-progress`
- `connection-banner`
- `phase-header`
- `phase-directive`
- `role-panel`
- `vote-status`
- `outcome-summary`
- `sticky-action-bar`

### Shared / payload changes

| Item                                  | Change                                                                                                                           |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `base`                                | Typography helpers (`gs-data`, `gs-micro`, `gs-eyebrow-dotted`), `--type-scale-micro`, `--font-data`, expanded `ConnectionState` |
| `theme-gamescience` / `theme-citadel` | `--font-data`, `--glow-critical` alias, action-bar tokens, domain hooks, Separator hairline theme rules                          |
| `separator`                           | optional `treatment="hairline"`                                                                                                  |
| `participant-status`                  | maps broader `ConnectionState` values onto compact ConnectionStatus                                                              |

### Deferred (not shipped)

DiscussionView, VoteView, SharedVoteReveal, ParticipantResults, SharedResults,
FacilitatorDebrief, LockedSelectionPanel, AttentionRedirectBanner, CompanyContext,
and a shared option-slot colour ramp.

## Consumer actions

1. **Pin** to `versions/0.5.0`.
2. Reinstall `base` and your theme to receive typography / glow-critical /
   action-bar token updates.
3. Reinstall `separator` if you want `treatment="hairline"`.
4. Install domain items **on demand** only when a screen needs them.
5. Do **not** automatically replace local discussion / vote / results views.
6. Map local candidates incrementally; keep timing, voting, role resolution,
   outcome taxonomy, charts, radar, and choreography application-owned.
7. Record which local components were replaced in the project state record.

## Compatibility notes

- Canonical critical glow role remains danger-aligned; `--glow-critical` is a
  compatibility alias of `--glow-danger` (Citadel) / focus shadow (Gamescience).
- Application migration aliases such as `--field`, `--pacific`, `--critical`,
  `--text-hi` must stay out of the registry contract.
- No `p-*` / `d-*` typography classes ship in registry source.

## Unchanged

- Prior immutable locks and snapshots (`0.1.0`–`0.4.1`)
- Join / lobby / shell pattern public contracts (aside from shared base/theme)
