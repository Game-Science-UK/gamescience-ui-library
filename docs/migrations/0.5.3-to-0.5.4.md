# 0.5.3 → 0.5.4

Patch release. Public component APIs and theme contracts remain
backward-compatible. Immutable `0.5.3` artefacts are unchanged.

## What changed

1. **Migrate coverage ledger hardening** — evidence references (not bare A–E
   booleans), discovery reconciliation, Storybook rendered-reference phase,
   state-interaction matrix, compiled-selector + CSS cascade gates, semantic
   wrapper discovery, risk levels, intent-based full vs safe mode, audit
   freshness, retained-approved regression checks, and evidence storage paths.
2. **Migrate composer modules** — shared `site/migration-modules/*` and public
   coverage/state docs aligned with the updated skill doctrine.
3. **Pages deploy trigger** — GitHub Pages workflow deploys from `main` only;
   `v*` tags are release markers and no longer start a second deploy.
4. **Version metadata** — registry item `meta.version` and `@gamescience/base`
   consumer guidance stamp to `0.5.4`. No source component contract changes.

## Consumer actions

1. **Optional pin** to `versions/0.5.4` when you want the current library pin.
2. **No component reinstall required** for visual or API behaviour.
3. If you pin to `0.5.4`, **diff then reinstall** `@gamescience/base` so
   `src/lib/version.ts` and `src/docs/gamescience-ui*.{json,md}` report
   `0.5.4`.
4. Prefer the updated migrate / validate doctrine (or regenerate a migrate brief
   from the Pages composer) for new migrations.
5. No route, pattern, or domain component contract changes.

## Unchanged

- Catalogue item names and count (no additions or removals)
- Theme CSS and token contracts from 0.5.3
- Pattern and domain component contracts from 0.5.3
