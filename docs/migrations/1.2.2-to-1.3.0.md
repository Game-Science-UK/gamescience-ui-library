# 1.2.2 → 1.3.0

Minor release. Adds the `sentinel` theme with cinematic (default) and
restrained registers. Existing themes, item names, and prop contracts remain
valid. Immutable `1.2.2` (and earlier) artefacts remain available and unchanged.

## What changed

1. **New theme** (`category: "theme"`):
   - `theme-sentinel` — void-field visual identity applied through
     `data-theme="sentinel"`. No theme-specific React forks.
2. **Registers** — Sentinel supports `data-register="cinematic"` (default) and
   `data-register="restrained"`. Set via optional `register` on
   `GameScienceProvider` so portals (Sonner, Radix) inherit the attribute.
3. **Shared hooks** (additive):
   - `.gs-panel-wash` on `Panel` (paints only under cinematic Sentinel)
   - `.gs-overlay` on dialog overlay
   - `.gs-display-hero`, `.gs-title-page`, `.gs-title-section` type roles
   - `data-state="breached"` ash treatment on `.gs-card` under Sentinel
4. **`base`** — `SUPPORTED_THEMES` includes `sentinel`; typography aliases;
   provider register sync.

Gamescience and Citadel continue to work unchanged. Red remains reserved for
the overrun / danger token only.

## Consumer actions

1. **Pin** to `versions/1.3.0` when adopting Sentinel or the new hooks.
2. **Install** the theme if you want Sentinel:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.3.0/r/theme-sentinel.json"
   ```

3. **Reinstall `base`** so `GameScienceProvider` accepts `theme="sentinel"` and
   optional `register`, and so foundations pick up the type-role aliases:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.3.0/r/base.json"
   ```

4. Optionally reinstall `panel`, `card`, `dialog`, `display-heading`, and
   `facilitator-shell` for the additive `gs-*` class hooks.
5. Load Archivo, Instrument Sans, and IBM Plex Mono at the application layer
   (see [font-loading.md](../font-loading.md)). Do not add remote font `@import`
   to theme CSS.
6. Application-owned globe, DataRain, LobbyRadar, boot choreography, and audio
   stay out of the registry — compose them beside shells if needed.
7. Consumers staying on Gamescience or Citadel need no visual migration;
   reinstall `base` only if you want the new `register` prop and theme slug.

## Unchanged

- Existing item names and prop contracts (the 1.2.2 set)
- Gamescience and Citadel theme CSS identity
- Required token names in `theme-contract.ts` (Sentinel implements the same set)
