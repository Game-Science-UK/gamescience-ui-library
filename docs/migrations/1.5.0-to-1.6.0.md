# 1.5.0 → 1.6.0

Additive. Adds the `globe` display component and `--globe-*` tokens across `base`
and the three themes. No existing prop contract changed.

## What changed

|               | Items                                                                                                                                                |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Added**     | `globe`                                                                                                                                              |
| **Changed**   | `base` (globe token defaults in foundations; globe marker styles), `theme-gamescience`, `theme-citadel`, `theme-sentinel` (globe token declarations) |
| **Unchanged** | All other item names, prop contracts, and payloads                                                                                                   |

Projects that do not install `globe` are unaffected. Reinstall `base` for the
foundation defaults and marker styles, and reinstall your theme to pick up its
`--globe-*` declarations.

## Globe

A rotating hex-tessellated globe for shared displays, with markers, rings, arcs
and site points. It is the library's first **theme-specific visual** — a
component whose whole identity comes from the theme, rather than a shared
primitive.

```bash
npx shadcn@latest add @gamescience/globe
```

**It is heavy.** Installing it adds `three`, `react-globe.gl`, `topojson-client`,
`world-atlas` and `h3-js` — roughly 57 MB installed. Install it only for
displays that render a globe.

The component is client-only: it loads world topology and tessellates it on
first mount. Render it behind a client-only boundary if the consuming app
server-renders.

## Globe theme tokens

Optional extensions, **not** added to `REQUIRED_THEME_TOKENS` — most games never
render a globe, and forcing every future theme to declare six globe tokens would
be the wrong trade.

| Token                                                                   | Purpose                                                           |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `--globe-atmosphere`                                                    | Rim halo, default arc and ring colour. Falls back to `--primary`. |
| `--globe-hex`                                                           | Land dot colour. Falls back to the atmosphere.                    |
| `--globe-marker`                                                        | Default marker colour. Falls back to the atmosphere.              |
| `--globe-surface`                                                       | Sphere body. Defaults to a dark neutral.                          |
| `--globe-specular`                                                      | Highlight. Falls back to `--border-strong`.                       |
| `--globe-opacity`, `--globe-hex-opacity`, `--globe-atmosphere-altitude` | Numeric tuning.                                                   |

All three shipped themes declare a globe: Sentinel an ice-rimmed void sphere,
Citadel a receding HUD hologram, GameScience a solid navy body on its light
field.

**Note for theme authors:** declare these inside your theme block, not at
`:root`. A custom property that aliases another is computed where it is
declared, so a `:root`-level `--globe-hex: var(--primary)` would inherit frozen
and ignore the active theme.
