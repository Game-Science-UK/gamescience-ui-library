# 1.2.0 → 1.2.1

Patch release. Visual/layout correction to two pattern blocks. No prop contract,
token, theme, or item-name changes. Immutable `1.2.0` (and earlier) artefacts
remain available and unchanged.

## What changed

1. **`create-session`** — the panel now sits inside a `max-w-md` wrapper, and the
   `data-state` attribute moved to that wrapper so the whole surface (not just the
   panel chrome) reflects the `editing` / `ready` state.
2. **`join-flow`** — the panel now sits inside a `max-w-md` wrapper, replacing the
   previous `max-w-content` sizing so the card matches the participant column width.

Both are markup/class refinements to existing items; the exported props and state
machine are unchanged.

## Consumer actions

1. **Pin** to `versions/1.2.1` when adopting the layout correction.
2. **Diff then reinstall** the affected patterns you use:

   ```bash
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.2.1/r/create-session.json" --diff
   npx shadcn@latest add "https://game-science-uk.github.io/gamescience-ui-library/versions/1.2.1/r/join-flow.json" --diff
   ```

3. Consumers not using either pattern require no action; existing installations
   continue to work unchanged.

## Unchanged

- All item names and prop contracts (the 1.2.0 set)
- Theme and foundation token contracts
- The 1.2.0 pattern suite and component catalogue
