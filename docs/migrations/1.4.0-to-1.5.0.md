## Sentinel

Void-field theme re-derived from the Sentinel 4.0 application through the
revised extraction process. Two registers, selected on the root provider:

```tsx
<GameScienceProvider theme="sentinel" context="participant">        {/* cinematic */}
<GameScienceProvider theme="sentinel" context="participant" register="restrained">
```

`cinematic` is the default and applies automatically — Sentinel is the first
theme to declare a default register through `THEME_DEFAULT_REGISTERS`.

Grammar: near-black void field, ice (cinematic) or indigo (restrained) primary,
violet emphasis and critical state, amber warning, uniformly square geometry,
elevation by surface step rather than drop shadow, panel-surfaced controls with
a coloured border rather than a solid fill.

Fonts are application-owned: Archivo (display), Instrument Sans (body),
IBM Plex Mono (data/labels). See [font-loading.md](../font-loading.md).

```bash
npx shadcn@latest add @gamescience/theme-sentinel
```

## Colour roles

- **Ice** `#7FD6FF` (cinematic) / **indigo** `#7C87F8` (restrained) — `--primary`.
  The primary action is a 10% ice tint over the raised surface with an ice
  border, never a solid fill. Ice also carries rules, halos, progress and focus.
- **Violet** `#B983FF` — `--secondary`, the committed-state accent. The secondary
  _button_ stays neutral panel-and-border; violet reads as state, not as a control fill.
- **Danger is amber** (`#C08C3C`), not red. Red exists once in the source, on the
  OVERRUN stamp, and the theme never emits it.

Controls are sized by `size`, never by intent — `intent` selects colour only.
The control ladder is 40 / 44 / 52px, matching the participant context. The
source's 66px full-width promoted CTA is an application layout concern, not a
registry size step.

## Coverage

Grammar confidence 67% observed / 33% source-declared. Catalogue coverage 86%
specified — 41% from evidence, 45% projected from the theme's stated grammar.

Left on contract tokens, with no rule: Slider, Accordion, Breadcrumb, Pagination,
Calendar, Chart, Carousel, Sidebar. The source has no counterpart for these and
no grammar rule reaches them.

Facilitator and shared-display treatments are source-declared only — no runtime
session was joined, so density and distance-legibility values are unmeasured.

## Deliberate deviations from source

Both are source defects the extraction flagged rather than fidelity breaks:

- **A focus ring exists.** The source has no `:focus-visible` treatment anywhere,
  so keyboard operation is invisible. The theme supplies an ambient-accent ring.
- **Dim foreground lifted** from `#5B6376` to `#6E7789`. The source value sits at
  roughly 3.1:1 on panel and is used at 9–10px, below WCAG AA.

Not reproduced: the source's register overrides fail to reach Tailwind colour
utilities because `@theme` bakes literals, so `restrained` only changes rules and
the body background there. This theme drives every utility from the same
variables the registers override, so both registers work fully.
