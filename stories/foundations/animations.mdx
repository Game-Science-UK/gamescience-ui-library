# Animations

Motion is tokenised (`--duration-fast`, `--duration-standard`, `--duration-emphasis`, `--press-scale`, `--hover-translate`) and respects `prefers-reduced-motion`.

Press feedback uses the `.gs-pressable` utility (wired into interactive primitives). Loading states use `Spinner` and `Skeleton` — theme CSS may add subtle keyframes under Citadel.

## Tokens

| Token | Role |
| --- | --- |
| `--duration-fast` | Micro interactions |
| `--duration-standard` | Default transitions |
| `--duration-emphasis` | Emphasised motion |
| `--press-scale` | Active press scale for `.gs-pressable` |
| `--hover-translate` | Optional hover lift |

Reduced motion collapses durations to `0ms` / near-instant animations via `src/foundations/motion.css`.
