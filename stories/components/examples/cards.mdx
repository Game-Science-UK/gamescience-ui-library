# Cards

Use **Panel** for operational game surfaces (lobby chrome, phase content, facilitator consoles). Use **Card** for denser content blocks inside those surfaces.

Avoid inventing `GlassCard` or theme-named card forks. Elevation and emphasis come from semantic props (`elevation`, `emphasis`) and theme tokens.
