# Forms

Form compositions use approved primitives: `Label`, `Input`, `Textarea`, `Checkbox`, `Switch`, `RadioGroup`, `Select`, `Slider`, `InputOTP`, and `Form` helpers from React Hook Form.

Prefer semantic props (`disabled`, `loading` on actions) and keep validation / submit ownership in the application.
