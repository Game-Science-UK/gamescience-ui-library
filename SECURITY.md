# Security Policy

## Supported versions

Security fixes are applied to the current published GameScience UI registry version on `main` and to tagged releases when practical.

## Reporting a vulnerability

Do **not** open a public GitHub issue for security-sensitive reports.

Email the GameScience engineering maintainers responsible for this repository, or use the organisation’s private security reporting channel.

Include:

- affected version / commit
- impact description
- reproduction steps where safe to share
- any suggested mitigation

## Scope notes

This repository publishes a static shadcn source registry and design-system code. It does not host production game backends. Still treat leaked credentials, private client assets, or confidential content as security incidents.
