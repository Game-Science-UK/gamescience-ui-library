## Theme validation lens — Gamescience

Selected theme: **gamescience**

Migrated screens must derive visual identity from `@gamescience/theme-gamescience` / `gamescience.css`, not local CSS forks.

Expect a clear, restrained, enterprise-ready identity: light surfaces, semantic blues, readable typography, moderate radii, and calm elevation.

Do **not** create Gamescience-named component forks. Theme identity stays in theme CSS + semantic tokens.
