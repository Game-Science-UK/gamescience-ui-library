## Theme validation lens — Citadel

Selected theme: **citadel**

Migrated screens must derive visual identity from `@gamescience/theme-citadel` / `citadel.css`.

Validation lens (not permission to fork components):

- deep navy field
- Pacific primary
- Cobalt emphasis
- amber warning
- square geometry
- luminous fine borders
- restrained glow
- technical label typography
- context-aware shell treatment
- no generic rounded SaaS card appearance

Do **not** create `CitadelButton` or other Citadel-specific component APIs.
